# Расписание УрСЭИ — стартовый проект

Тёмный адаптивный сайт + Python-проверка источника + GitHub Actions.

## Важно о текущем состоянии

Официальные страницы для проверки:
- https://ursei.su/asu/ssched.php
- https://ursei.su/Services/StudSched
- https://ursei.su/Services/SchedTeacher

Проект **не подставляет выдуманные пары**. Парсер проверяет доступные страницы и пытается извлечь расписание из HTML-таблиц. Если подходящие данные не обнаружены, он завершится с ошибкой и оставит прежний JSON нетронутым.

Перед включением автоматического обновления запусти скрипт вручную и проверь отчёт. Если сайт загружает расписание через JavaScript или требует форму/сессию, понадобится исследовать реальный запрос источника и адаптировать парсер. Не обходи авторизацию, CAPTCHA или технические ограничения.

## Локальный запуск

Требуется Python 3.11+.

```bash
python -m venv .venv
# Windows:
.venv\\Scripts\\activate
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
python scripts/scrape_schedule.py --probe
```

Команда `--probe` создаёт `probe-report.json` с результатами проверки. Чтобы записывать расписание, после подтверждения правильного способа извлечения данных запусти:

```bash
python scripts/scrape_schedule.py --update
```

Если парсер не может надёжно найти данные, он ничего не публикует.

## GitHub Pages

1. Создай публичный репозиторий на GitHub.
2. Загрузи содержимое проекта.
3. Открой **Settings → Pages**.
4. В разделе Build and deployment выбери **Deploy from a branch**, ветка `main`, папка `/docs`.
5. Сохрани настройки и дождись публикации.

Сайт может отображаться даже до подключения парсера, но расписание останется в статусе «Источник ещё не подключён», пока не появятся проверенные данные.

## Автоматизация

Workflow в `.github/workflows/update-schedule.yml` запускается по расписанию и вручную. Он коммитит JSON только если скрипт успешно подтвердил извлечение расписания. Сейчас workflow намеренно не подменяет отсутствующие данные вымышленными значениями.

GitHub Actions по расписанию может запускаться с задержкой; это не гарантия обновления ровно в конкретную минуту.

## Данные и ограничения

- `docs/data/schedule.json` — данные расписания, изначально пустые.
- `docs/data/bells.json` — расписание звонков, изначально не подтверждено.
- Название и логотип УрСЭИ используй только после получения необходимых разрешений.
- До согласования с институтом обозначай проект как независимый, неофициальный сервис.
